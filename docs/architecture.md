# ContextFlow Architecture

## Project

ContextFlow is an AI-assisted context-to-workflow automation system.

## Core Principle

AI understands.
Rules decide.
Workflows execute.
The database remembers.
Security controls the data.
Humans approve important decisions.

## High-Level Flow

User
→ Chrome Extension
→ Input Validation
→ Privacy Filter
→ Context Engine
→ AI Analysis
→ Schema Validation
→ Human Review
→ Task Service
→ Workflow Engine
→ Database / n8n
→ Dashboard

## Core Goals

- Capture relevant user-provided context
- Extract actionable tasks and deadlines
- Preserve source information
- Manage dependencies
- Track task state
- Schedule reminders
- Detect meaningful changes
- Detect duplicates and conflicts
- Protect sensitive information
- Maintain audit history
- Recover safely from failures
- Support future extensions
